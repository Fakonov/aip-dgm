命令速查

怎么用

  1. 用 Edge / Chrome 打开本文件，点右上「连接设备」，选 USB 串口。
  2. ROM / 存档：8 个槽的上传 / 读出 / 启动 / 擦除；存档导出、导入、重置。
  3. 养成：当前数码兽、影响进化路线的全部数据、SKIP TIME、进化条件。
  4. 调试：内存、原始命令、CRC 工具。

固件协议见调试页速查表；本工具单文件、无外部依赖。
