支持一次多选，自动铺空槽。

命令速查

ROMINFO                       扫描 8 个槽
ROMIN <slot> <len> <crc> [名]  上传（→ ROMREADY → hex → ROMEND）
ROMOUT <slot>                 读出
ROMBOOT <slot> / ROMDEL <slot> 启动 / 擦除
SAVEOUT / SAVEIN              存档导出 / 导入
SAVEDEL <slot>                清掉该槽存档
STATE                         一行完整养育数据
AGES                          8 个槽的 PLAY TIME
RAM                           0x00–0xFF 内存
DUMP / PET / SKIP <分钟>      诊断 / 摘要 / 跳过时间
CONSOLE 0 行

怎么用

  1. 用 Edge / Chrome 打开本文件，点右上「连接设备」，选 USB 串口。
  2. ROM / 存档：8 个槽的上传 / 读出 / 启动 / 擦除；存档导出、导入、重置。
  3. 养成：当前数码兽、影响进化路线的全部数据、SKIP TIME、进化条件。
  4. 调试：内存、原始命令、CRC 工具。

固件协议见调试页速查表；本工具单文件、无外部依赖。
